Prepare a new comparison

This portable viewer reads saved files offline. To prepare and run your own comparison, start the private local workspace from the tool checkout:

python3 -m sim workspace --store /path/to/private-comparisons

Open the private link printed by that command. Choose your scenario and two documents, inspect the exact inputs, then explicitly start. Nothing runs from this offline page.

Docker and the chosen image must already be available. No image or model is downloaded. Coding agents require the existing cached setup and explicit --allow-agents authorization.
